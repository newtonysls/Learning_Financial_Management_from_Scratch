# A 股公司基本面分析 Agent 设计

## 目标与边界

构建一个本地运行的网页 Agent。用户输入单只 A 股代码，可附加本地文档，系统从公开来源采集公司、公告、财务、行情、股权、新闻和舆情资料，生成带图表、来源引用和风险提示的中文深度基本面报告，并可导出 Markdown 与 PDF。

一期覆盖沪深 A 股，不提供批量选股、自动交易、收益承诺或个性化投资建议。系统给出研究辅助结论，所有关键事实必须可追溯。

## 技术原则

1. **事实与写作分离**：程序负责采集、规范化和指标计算；模型负责归纳、交叉验证及表达。
2. **官方来源优先**：交易所、巨潮资讯、公司官网和定期报告优先；聚合站与百科仅作补充。
3. **证据优先**：财务数字、新闻判断与风险结论必须关联来源、发布日期、报告期和抓取时间。
4. **免费优先**：使用公开网页、公开接口与本地文档，不依赖付费金融 API；来源不可用时明确降级。
5. **可复算**：估值、财务比率、最大回撤和趋势指标由确定性代码计算，不交给模型猜测。
6. **模型可切换**：默认使用 Cursor Agent SDK 托管模型，保留 OpenAI 兼容接口配置层。

## 总体架构

项目采用 Node.js/TypeScript 单仓库，以 npm 脚本直接启动：

- `bot/`：Cursor Agent SDK Agent、分析指令和受控工具。
- `server/`：本地 HTTP API、任务编排、采集适配器、文档解析、指标计算、缓存与报告数据服务。
- `web/`：React 网页，提供股票代码输入、文档上传、分析进度、报告阅读和导出。
- `data/`：SQLite 元数据、全文索引、缓存文件和用户上传文件；不提交 Git。
- `evals/`：Agent 冒烟及证据约束评测。

一期保持单机、单用户和单进程任务队列。耗时采集以任务状态流呈现，不引入 Redis 等额外基础设施。

## 核心组件

### 1. 股票标识解析

接受 `600519`、`600519.SH`、`sh600519` 等形式，规范化为代码、交易所和统一证券 ID。拒绝非沪深 A 股标识，避免错误查询。

### 2. 数据源注册与证据分级

每个数据源由独立适配器实现，返回统一 `EvidenceRecord`：

- A 级：交易所、巨潮资讯、公司官网、法定定期报告。
- B 级：权威财经媒体、政府网站、主流报刊。
- C 级：公开行情聚合接口、百度百科、门户转载。
- D 级：论坛、股吧、自媒体和网友评论。

记录字段包括来源 URL、标题、发布者、发布时间、抓取时间、报告期、正文摘要、内容哈希、证据级别和采集状态。事实冲突时以级别、报告期和发布时间排序，并在报告中披露冲突。

首批来源：

- 公司与公告：巨潮资讯、上交所、深交所、公司官网。
- 财务与行情：公开行情接口，必要时用 AkShare 兼容适配器作为可选补充；定期报告数字用于校验。
- 背景资料：百度百科与公司官网。
- 新闻：百度新闻搜索结果、主流财经媒体公开页面及公司新闻。
- 舆情：东方财富股吧等公开可访问页面；不可访问时不绕过验证码或访问控制。

所有采集器设置超时、速率限制、User-Agent、重试上限和缓存。遵守 robots.txt、网站条款及访问限制，不破解验证码、不登录抓取。

### 3. 本地知识库

支持 PDF、TXT、Markdown、HTML、CSV 和 XLSX；DOCX 作为后续兼容项。处理流程：

1. 文件类型、大小和哈希校验。
2. 提取文本与表格，保留页码、工作表和单元格范围。
3. 中文段落切分，生成可引用片段。
4. 使用 SQLite FTS5 做关键词检索；一期不强制下载嵌入模型。
5. 查询时将股票代码、公司名称、报告期和主题作为混合检索条件。

本地文档证据独立标识，引用显示文件名和页码/表格位置。

### 4. 规范化与量化引擎

统一金额单位、币种、报告期和复权口径，生成结构化快照。确定性计算：

- 营收、利润、经营现金流及同比/复合增长率。
- 资产、负债、现金、应收、存货、商誉和资本开支。
- 资产负债率、流动/速动比率、利息保障倍数。
- 毛利率、净利率、ROE、ROA、现金利润比。
- PE、PB、PS 等可获得估值指标，并注明时点。
- 日/周/月行情、成交量、均线与波动率。
- 截至分析日的周、月、季、年区间最大回撤；同时列出区间起止、峰值、谷值和公式。

缺失分母、负值估值和报告期不一致不得强算，返回“不可比/数据不足”及原因。

### 5. 股权与关系图谱

从公告和公开股东数据构建轻量关系图：

- 控股股东、实际控制人、前十大股东。
- 董事、监事、高管及关键变更。
- 主要子公司、关联方。
- 能被公开证据支持的上游供应方与下游客户。

严禁把行业常识写成具体供销关系；未披露名称时仅报告集中度和披露口径。

### 6. 新闻、政策与舆情

新闻按来源、日期、事件主体去重，再分类为正面、负面和中性。情感标签只是检索辅助，最终判断由 Agent 结合事实与影响范围完成。

政策分析覆盖国家产业政策、监管、税费、海关、出口管制、地缘政治和地方政策。每项影响必须给出传导路径，而非仅做关键词匹配。

舆情将“事实报道”“专家/媒体观点”“普通网友观点”分栏；输出样本规模、时间窗口和来源偏差。D 级舆情不得单独支撑重大风险结论。

### 7. Agent 编排

Agent 暴露只读工具：

- 查询分析任务与结构化指标。
- 检索证据及打开证据片段。
- 获取关系网络、新闻聚类和舆情样本。
- 生成/读取报告工件。

Agent 指令要求先构建论点—证据映射，再写报告；对关键数字做交叉核验；区分事实、推断和观点；禁止补造缺失数据。模型提供方封装为配置项，默认 Cursor，后续可填入 OpenAI 兼容 `baseUrl`、模型名和密钥。

## 报告结构

1. 执行摘要：核心判断、证据充分度、重要机会与风险。
2. 公司画像：介绍、规模、业务分部、商业模式与竞争位置。
3. 产业链：上游、下游、客户/供应商集中度及议价能力。
4. 财务质量：流水口径说明、营收、利润、现金流、资产与负债。
5. 股权与治理：股东、实控人、董监高、关联关系及治理风险。
6. 市场表现：股价、成交量、估值、波动率和多周期最大回撤。
7. 新闻与经营动态：正面、负面、中性及经营情况报道。
8. 政策与外部环境：政策、海关、宏观及地缘风险传导。
9. 舆情：网友认知、媒体观点、分歧与样本偏差。
10. 风险矩阵：概率、影响、证据、领先指标和缓释因素。
11. 情景分析：基准、乐观、悲观三种定性情景，不给目标股价。
12. 数据局限、免责声明和完整引用清单。

## 图表

- 收入、利润、现金流年度/季度趋势。
- 毛利率、净利率、ROE 与负债率趋势。
- 资产与负债结构。
- K 线/收盘价、成交量、均线与回撤曲线。
- 周、月、季、年最大回撤对比。
- 股东及关联关系网络。
- 新闻情感与事件时间线。
- 舆情来源和观点分布。
- 风险矩阵。

网页使用交互式图表；PDF 导出时转为静态图。每张图显示数据口径、区间和来源。

## 数据流

1. 用户输入代码并上传可选文档。
2. 服务端规范化股票标识并创建任务。
3. 并发采集各来源，失败适配器不阻塞其他来源。
4. 文档解析、正文去重、证据分级和结构化落库。
5. 量化引擎计算指标并执行一致性校验。
6. Agent 检索结构化事实和证据，生成章节化报告。
7. 服务端校验引用完整性与关键数字覆盖率。
8. 网页渲染报告和图表，用户导出 Markdown/PDF。

同一股票在缓存有效期内复用数据；用户可主动刷新。每次报告保存分析时间与数据截止时间，保证可复现。

## 异常与降级

- 单一来源失败：展示缺失项和失败原因，继续生成可用章节。
- 官方与聚合数据冲突：官方优先，报告中列出差异。
- 新闻正文受限：只引用合法获得的标题和摘要，不伪造全文。
- 本地文件损坏或加密：拒绝文件并给出明确提示。
- 数据不足：不生成确定性结论，标注置信度。
- 模型不可用：保留已采集数据和图表，允许稍后重试报告生成。
- 采集超时：有限次数指数退避，禁止无限重试。

## 安全与隐私

- 上传文件限制扩展名、MIME、大小和路径，随机化存储名，防止路径穿越。
- 网页抓取阻止内网、环回、元数据地址和非 HTTP(S) 协议，防止 SSRF。
- HTML 提取后再展示，禁止执行远端脚本。
- API 密钥仅从环境变量读取，不写入日志、数据库或前端。
- 报告明确注明数据截止时间、来源局限和“非投资建议”。

## 验收与测试

### 单元测试

- 股票代码规范化。
- 财务单位及报告期归一化。
- 各周期最大回撤边界条件。
- 证据分级、去重和冲突选择。
- URL 安全校验和上传文件校验。

### 集成测试

- 使用固定夹具模拟官方公告、行情、新闻和舆情，避免测试依赖外网。
- 从代码输入到结构化快照、图表数据和 Markdown 报告的完整流程。
- 单源故障、数据冲突、模型故障和文件解析失败的降级流程。

### Agent 评测

- 必须调用证据工具。
- 每个关键财务数字带引用。
- 不引用的结论不得伪装为事实。
- 能明确识别数据不足和互相冲突的证据。

### 人工验收样例

至少选择一家沪市大型公司、一家深市公司和一家财务/舆情复杂公司，核对报告完整性、图表口径、引用可访问性和多周期回撤计算。

## 交付判定

本地执行 npm 命令后可打开网页；输入有效 A 股代码并可选上传文档；系统显示采集进度，产出完整章节、交互图表、证据引用、数据局限与风险提示；Markdown 和 PDF 可成功下载；关键指标可由测试夹具复算；任一非关键来源失败时仍能给出透明的降级结果。
