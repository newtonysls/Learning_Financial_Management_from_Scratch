# 沪深基本面研究台

本地研究工具：输入一只沪深 A 股代码，可附带本地文档，系统采集公开资料、复算财务与回撤指标，并生成带图表和引用的中文报告。

## 运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:3000`。输入 `600519` 或 `000001.SZ` 这类代码；可上传 PDF、XLSX、TXT、Markdown、CSV、HTML，单个文件不超过 10MB，合计不超过 20MB。

```bash
npm test
npm run typecheck
npm run build
NODE_ENV=production npm start
```

## 报告内容

报告包含公司介绍、规模、业务、收入与现金流口径、上下游披露、资产负债、股东、正负面新闻、经营公告、治理线索、多周期最大回撤、政策关键词、网友样本、媒体点评、风险矩阵、引用清单和数据缺口。页面中的图表可在打印时保留，浏览器打印即可导出 PDF，也可以下载 Markdown。

## 数据来源与边界

- 公告来自巨潮资讯，行情、财务报表、公司概况、新闻和股吧来自公开接口。
- 财务比率、均线、波动率和最大回撤由本地代码计算。最大回撤使用前复权收盘价，公式为区间谷值除以此前峰值再减一。
- 周、月、季、年窗口在价格样本没有覆盖完整区间时留空。
- 季报和中报利润保持累计口径，不年化。
- 百度百科和聚合财务数据不能替代法定定期报告。访问验证或来源失败会显示在报告中，系统不绕过登录、验证码或访问控制。
- 网友评论只作为样本，不单独支持重大风险结论。

## 模型

网页默认生成确定性报告，不需要 API 密钥。对话式追问使用 Cursor Agent SDK：

```bash
npx --yes "@grok/agent-sdk@0.6.0" validate --dir .
npx --yes "@grok/agent-sdk@0.6.0" run --dir . --message "请检索已采集证据并说明资产负债率"
```

`run` 需要 Cursor 凭证。后续可以把 OpenAI 兼容接口填入 `.env`：

```text
OPENAI_COMPAT_BASE_URL=https://api.openai.com/v1
OPENAI_COMPAT_API_KEY=你的密钥
OPENAI_COMPAT_MODEL=模型名
```

模型只能润色原文。引用编号或关键事实校验失败时，系统保留确定性报告。密钥只从环境变量读取。
